# 健身助手 (Etraining)

一个纯前端的个人健身记录工具，无需后端，数据存储在浏览器本地。

## 功能

- **训练记录**：计时器、计次/计时两种运动模式、组间休息倒计时
- **动作库**：预设 10 个常用动作，支持自定义添加、编辑、删除
- **训练统计**：按周/月/年查看训练时长趋势、计次与计时动作分别统计
- **数据持久化**：所有数据保存在 localStorage，支持导出备份

## 使用

直接打开 `index.html` 即可使用，无需安装任何依赖。
