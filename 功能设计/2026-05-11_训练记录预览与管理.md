# 功能设计 - 训练记录预览与管理

> 提交时间：2026-05-11 22:40

## 需求概述
- **目标**：支持查看历史训练记录详情，并能删除错误记录，删除后统计数据同步更新
- **用户场景**：用户误操作结束训练产生空记录，需要删除；用户想查看某次训练的具体动作和组数
- **优先级**：高

## 技术方案

### 涉及文件
- `js/storage.js` - 新增删除训练记录方法
- `js/app.js` - 首页记录列表改造、详情展开/收起、删除操作
- `js/workout.js` - 训练记录增加保存分类字段
- `css/style.css` - 详情展开和删除按钮样式

### UI 设计
```
┌─────────────────────────────────────────┐
│ 2026-05-11     00:15:30    [删除]        │  ← 点击展开详情
│                 3 个动作 · 9 组           │
├─────────────────────────────────────────┤  ← 展开区域
│ 俯卧撑 [胸部]                            │
│ 第1组: 12次 / 第2组: 10次 / 第3组: 8次    │
│ 深蹲 [腿部]                              │
│ 第1组: 15次 / 第2组: 15次 / 第3组: 12次   │
│ 平板支撑 [核心]                           │
│ 第1组: 01:00 / 第2组: 00:45              │
└─────────────────────────────────────────┘
```

### 接口设计

**Storage 方法**:

| 方法 | 说明 |
|------|------|
| `Storage.deleteWorkout(id)` | 根据 id 删除一条训练记录 |

**App 方法**:

| 方法 | 说明 |
|------|------|
| `App.toggleWorkoutDetail(id)` | 切换训练详情的展开/收起 |
| `App.deleteWorkout(id, event)` | 确认后删除记录，刷新首页和统计 |

### 训练记录数据结构（更新）
```javascript
{
  id: string,
  date: "2026-05-11",
  startTime: timestamp,
  endTime: timestamp,
  duration: seconds,
  exercises: [
    {
      exerciseId: string,
      exerciseName: "俯卧撑",
      exerciseType: "count",
      exerciseCategory: "胸部",   // 新增字段
      sets: [{ reps: 12 }, { reps: 10 }]
    }
  ]
}
```

## 实现步骤
1. 在 `js/storage.js` 添加 `deleteWorkout(id)` 方法
2. 在 `js/workout.js` 的 `end()` 中记录 `exerciseCategory` 字段
3. 修改 `js/app.js` 的 `renderHome()`，每条记录添加删除按钮和可展开详情
4. 在 `js/app.js` 添加 `toggleWorkoutDetail()` 和 `deleteWorkout()` 方法
5. 在 `css/style.css` 添加详情展开区域和删除按钮样式

## 测试要点
- 首页最近训练列表每条记录显示"删除"按钮
- 点击记录行展开详情，显示动作名、分类、组数和每组数据
- 再次点击收起详情
- 删除空训练记录后首页列表更新
- 删除有数据的训练记录后统计页图表和摘要同步变化
- 旧记录（无 exerciseCategory 字段）正常显示，不报错
- 删除时弹出确认框，取消不执行
