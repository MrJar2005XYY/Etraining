# 功能设计 - 训练鼓励名言

> 提交时间：2026-05-11 22:30

## 需求概述
- **目标**：在训练过程中显示鼓励性名言名句，定期自动更换，提升训练动力和趣味性
- **用户场景**：用户训练时看到鼓励语获得动力；用户可自定义添加个性化的鼓励语
- **优先级**：中

## 技术方案

### 涉及文件
- `index.html` - 训练页名言显示区域、首页名言管理区域
- `js/storage.js` - 自定义名言存储
- `js/workout.js` - 内置名言数据、轮播逻辑
- `js/app.js` - 首页名言管理事件绑定
- `css/style.css` - 名言显示和管理样式

### 数据结构
```javascript
// localStorage key: 'fit_quotes'
// 自定义名言列表（字符串数组）
['自定义鼓励语1', '自定义鼓励语2', ...]

// 内置名言（硬编码在 workout.js 中，18 条）
// 训练时内置 + 自定义合并后随机打乱使用
```

### UI 结构
**训练页 — 名言显示**：
```
┌─────────────────────────────────┐

├─────────────────────────────────┤

├─────────────────────────────────┤
│  [选择动作 ▼]  [添加动作]        │
└─────────────────────────────────┘
```

**首页 — 名言管理**：


### 接口设计

**Storage 方法**:

| 方法 | 说明 |
|------|------|
| `Storage.getQuotes()` | 获取自定义名言列表（默认空数组） |
| `Storage.saveQuotes(quotes)` | 保存名言列表 |
| `Storage.addQuote(text)` | 添加一条自定义名言 |
| `Storage.deleteQuote(index)` | 按索引删除一条自定义名言 |

**Workout 方法**:

| 方法 | 说明 |
|------|------|
| `Workout.startQuote()` | 合并内置+自定义名言，随机打乱，启动30秒轮播 |
| `Workout.stopQuote()` | 停止轮播定时器，清空显示 |
| `Workout.showNextQuote()` | 切换到下一条名言，带0.5秒淡入淡出动画 |

**App 方法**:

| 方法 | 说明 |
|------|------|
| `App.bindQuoteManage()` | 绑定首页添加名言按钮和回车事件 |
| `App.renderQuoteList()` | 渲染自定义名言列表，内置名言不可删除 |
| `App.removeQuote(index)` | 确认后删除指定索引的自定义名言 |

### 轮播逻辑
```
start() 被调用
  ↓
合并名言：内置18条 + 自定义N条
  ↓
Fisher-Yates 随机打乱
  ↓
立即显示第一条
  ↓
setInterval 每30秒调用 showNextQuote()
  ↓
showNextQuote():
  1. 添加 fade-out 类（opacity → 0）
  2. 500ms 后更新文本，移除 fade-out（opacity → 1）
  3. 索引递增，取模循环
```

### 生命周期绑定
| 事件 | 动作 |
|------|------|
| `Workout.start()` | 调用 `startQuote()` |
| `Workout.end()` | 调用 `stopQuote()` |
| `App.init()` | 调用 `bindQuoteManage()` |
| `App.renderHome()` | 调用 `renderQuoteList()` |

### 数据导出/导入
- `exportData()` 导出时包含 `quotes` 字段
- `importData()` 导入时恢复自定义名言

## 实现步骤
1. 在 `js/storage.js` 添加 `QUOTES` key 和 get/save/add/delete 方法
2. 在 `index.html` 训练页添加 `#motivational-quote` 容器
3. 在 `index.html` 首页添加鼓励语录管理区域
4. 在 `js/workout.js` 添加 `BUILTIN_QUOTES` 数组和三个轮播方法
5. 在 `Workout.start()` 末尾调用 `startQuote()`
6. 在 `Workout.end()` 中调用 `stopQuote()`
7. 在 `js/app.js` 添加 `bindQuoteManage()` 和 `renderQuoteList()`
8. 在 `App.init()` 中调用 `bindQuoteManage()`
9. 在 `App.renderHome()` 末尾调用 `renderQuoteList()`
10. 在 `css/style.css` 添加名言显示和管理样式
11. 更新 `exportData()`/`importData()` 包含名言数据

## 测试要点
- 点击"开始训练"后名言出现在计时器下方
- 名言每30秒自动切换，带淡入淡出过渡效果
- 点击"结束训练"后名言消失
- 从导航栏进入训练页未开始计时时不显示名言
- 首页可添加自定义名言并显示在列表中
- 可删除自定义名言，内置名言不可删除
- 训练时内置+自定义名言混合随机轮播
- 导出数据包含自定义名言，导入后名言恢复
