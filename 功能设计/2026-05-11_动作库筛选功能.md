# 功能设计 - 动作库筛选功能

> 提交时间：2026-05-11 22:30

## 需求概述
- **目标**：在动作库页面增加筛选功能区，支持按部位分类和动作类型（计次/计时）进行组合筛选
- **用户场景**：动作数量增多后，用户需要快速定位特定类型的动作，如"胸部+计时"或"腿部+计次"
- **优先级**：中

## 技术方案

### 涉及文件
- `index.html` - 筛选栏 HTML 结构
- `js/exercises.js` - 筛选状态管理和过滤逻辑
- `js/app.js` - 页面切换时初始化筛选
- `css/style.css` - 筛选标签样式

### 数据结构
```javascript
// 筛选状态（Exercises 对象属性）
{
  _filterCategory: string,  // 当前部位筛选值，'all' 或具体分类名
  _filterType: string       // 当前类型筛选值，'all' | 'count' | 'time'
}
```

### UI 结构
```
┌─────────────────────────────────────┐
│ 部位：[全部] [胸部] [背部] [腿部] … │  ← 动态生成，与分类管理同步
│ 类型：[全部] [计次] [计时]           │  ← 静态固定
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│ 动作列表（根据筛选条件过滤）          │
└─────────────────────────────────────┘
```

- 筛选标签为药丸形按钮，选中态高亮（主题色背景 + 白色文字）
- 两个维度独立筛选、组合生效
- 点击"全部"重置对应维度的筛选
- 无匹配结果时显示"暂无匹配的动作"

### 接口设计
**新增方法**:

| 方法 | 说明 |
|------|------|
| `Exercises.renderFilterTags()` | 根据当前分类列表动态生成部位筛选标签，绑定点击事件 |
| `Exercises.bindFilterType()` | 绑定类型筛选标签的点击事件 |
| `Exercises.applyFilter()` | 根据 `_filterCategory` 和 `_filterType` 过滤动作列表并渲染 |

**修改方法**:

| 方法 | 变更 |
|------|------|
| `Exercises.renderList()` | 改为委托给 `applyFilter()` |
| `Exercises.handleAddCategory()` | 新增调用 `renderFilterTags()` 同步筛选标签 |
| `Exercises.handleRemoveCategory()` | 新增调用 `renderFilterTags()`，若删除的是当前选中分类则重置为"全部" |
| `App.showPage('exercises')` | 新增调用 `renderFilterTags()` 和 `bindFilterType()` |

### 筛选逻辑
```javascript
applyFilter() {
  let exercises = this.getAll();
  if (this._filterCategory !== 'all') {
    exercises = exercises.filter(ex => ex.category === this._filterCategory);
  }
  if (this._filterType !== 'all') {
    exercises = exercises.filter(ex => ex.type === this._filterType);
  }
  // 渲染过滤后的列表
}
```

## 实现步骤
1. 在 `index.html` 的分类管理区域和动作列表之间插入筛选栏 HTML
2. 在 `css/style.css` 添加 `.filter-bar`、`.filter-tag` 等样式
3. 在 `js/exercises.js` 添加 `_filterCategory`、`_filterType` 状态属性
4. 实现 `renderFilterTags()` 方法，动态生成部位筛选标签
5. 实现 `bindFilterType()` 方法，绑定类型筛选事件
6. 实现 `applyFilter()` 方法，包含完整的列表渲染逻辑
7. 修改 `renderList()` 委托给 `applyFilter()`
8. 修改 `handleAddCategory()` 和 `handleRemoveCategory()` 同步筛选标签
9. 修改 `app.js` 的 `showPage('exercises')` 初始化筛选

## 测试要点
- 进入动作库页面，筛选栏正确显示，"全部"默认选中
- 点击部位标签（如"胸部"），列表只显示对应分类的动作
- 点击类型标签（如"计时"），列表只显示对应类型的动作
- 组合筛选：同时选中部位和类型，结果取交集
- 点击"全部"重置对应维度，列表恢复
- 添加新分类后，部位筛选标签同步出现新选项
- 删除分类后，部位筛选标签同步移除
- 删除当前选中的分类，自动回退到"全部"
- 添加/编辑/删除动作后，筛选状态保持不变
- 无匹配结果时显示空状态提示

## 风险评估
- **筛选状态保持**：筛选状态存储在内存中（`_filterCategory`/`_filterType`），页面切换不丢失（因为 SPA 不销毁 DOM）
- **分类同步**：添加/删除分类时自动刷新筛选标签，不会出现标签与分类不一致的情况
- **删除选中分类**：已处理边界情况，自动重置为"全部"
