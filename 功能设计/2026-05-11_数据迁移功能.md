# 功能设计 - 数据迁移（导出/导入）

> 提交时间：2026-05-11 22:30

## 需求概述
- **目标**：支持将应用数据导出为 JSON 文件，并在其他设备/浏览器上导入恢复
- **用户场景**：用户更换浏览器、更换设备、或清除浏览器缓存前，需要备份和迁移数据
- **优先级**：高

## 技术方案

### 涉及文件
- `js/storage.js` - 导出/导入核心逻辑
- `js/app.js` - 事件绑定
- `index.html` - 首页数据管理区域
- `css/style.css` - 按钮样式

### 导出数据格式
```json
{
  "version": 1,
  "exportDate": "2026-05-11T12:00:00.000Z",
  "exercises": [ ... ],
  "workouts": [ ... ],
  "categories": [ ... ]
}
```

### 接口设计

| 方法 | 说明 |
|------|------|
| `Storage.exportData()` | 将 exercises、workouts、categories 打包为 JSON 文件并触发下载 |
| `Storage.importData(file, onSuccess, onError)` | 读取 JSON 文件，解析后写入 localStorage，回调通知结果 |

### 交互流程
1. 点击"导出数据" → 自动下载 `健身助手_备份_YYYY-MM-DD.json` 文件
2. 点击"导入数据" → 弹出文件选择器（仅接受 .json）
3. 选择文件后弹出确认框："导入将覆盖当前所有数据，确定继续？"
4. 确认后解析文件并写入 localStorage，成功提示"数据导入成功"
5. 导入失败（格式错误）弹出错误提示

## 实现步骤
1. 在 `storage.js` 添加 `exportData()` 和 `importData()` 方法
2. 在 `index.html` 首页添加"数据管理"区域（导出/导入按钮 + 隐藏的 file input）
3. 在 `css/style.css` 添加 `.data-section` 和 `.data-actions` 样式
4. 在 `app.js` 添加 `bindDataManage()` 方法绑定事件

## 测试要点
- 导出的 JSON 文件包含完整的 exercises、workouts、categories 数据
- 在另一浏览器导入该文件，数据完整恢复
- 导入时覆盖确认弹窗正常工作
- 导入格式错误的文件时显示错误提示
- 导入成功后首页摘要、动作库、统计数据同步更新
