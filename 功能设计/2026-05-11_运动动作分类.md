# 功能设计 - 运动动作分类（含自定义分类）

> 提交时间：2026-05-11 22:30

## 需求概述
- **目标**：为每个运动动作添加锻炼部位分类，便于用户识别运动锻炼的身体部位
- **用户场景**：按照运动的锻炼部位进行分类，支持自定义分类名称
- **优先级**：中

## 技术方案

### 涉及文件
- `js/storage.js` - 分类数据存储
- `js/exercises.js` - 运动数据结构和 CRUD 操作
- `js/workout.js` - 训练中的运动卡片渲染
- `js/app.js` - 事件绑定
- `index.html` - 动作库页面 HTML 结构
- `css/style.css` - 分类标签样式

### 数据结构
```javascript
// 运动对象
{
  id: string,
  name: string,
  type: string,      // "count" | "time"
  preset: boolean,
  category: string   // 锻炼部位分类
}

// 分类列表存储
// localStorage key: 'fit_categories'
['胸部', '背部', '腿部', '腹部', '肩部', '手臂', '核心', '全身']
```

### 预设动作分类
| 预设动作 | 分类 |
|---------|------|
| 俯卧撑 | 胸部 |
| 深蹲 | 腿部 |
| 仰卧起坐 | 腹部 |
| 引体向上 | 背部 |
| 平板支撑 | 核心 |
| 弓步蹲 | 腿部 |
| 波比跳 | 全身 |
| 开合跳 | 全身 |
| 登山跑 | 核心 |
| 靠墙静蹲 | 腿部 |

### 接口设计
**Storage 方法**:
- `Storage.getCategories()` - 获取分类列表
- `Storage.saveCategories(categories)` - 保存分类列表

**Exercises 方法**:
- `Exercises.getCategories()` - 获取分类列表
- `Exercises.addCategory(name)` - 添加自定义分类
- `Exercises.removeCategory(name)` - 删除分类
- `Exercises.add(name, type, category)` - 添加运动时传入分类
- `Exercises.renderList()` - 显示分类标签，编辑模式添加分类选择器
- `Exercises.populateSelect()` - 选择器显示格式：`动作名 [分类]`
- `Exercises.populateCategorySelect()` - 填充分类选择器
- `Exercises.renderCategoryList()` - 渲染分类管理列表
- `Workout.renderWorkoutExercises()` - 训练卡片头部显示分类标签
