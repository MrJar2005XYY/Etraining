# 功能设计 - 取消本次训练

> 提交时间：2026-05-11 22:30

## 需求概述
- **目标**：在训练页增加"取消训练"功能，允许用户放弃当前训练，不保存任何记录
- **用户场景**：用户误操作开始训练、或训练中途想放弃本次训练时，可以一键清空状态回到首页
- **优先级**：中

## 技术方案

### 涉及文件
- `index.html` - 训练页头部添加取消按钮
- `js/workout.js` - 新增取消方法
- `js/app.js` - 绑定取消按钮事件
- `css/style.css` - 取消按钮样式

### UI 设计
训练页头部右侧按钮区域：
```
┌──────────────────────────────────┐
│ 训练中          取消训练  结束训练 │
└──────────────────────────────────┘
```

- "取消训练"为红色文字按钮，位于"结束训练"左侧
- 点击后弹出确认框："确定取消本次训练？所有记录将不会保存"
- 确认后清空所有训练状态，跳转回首页

### 接口设计

**Workout 方法**:

| 方法 | 说明 |
|------|------|
| `Workout.cancel()` | 取消训练：停止计时器、停止名言轮播、清空所有状态（不保存记录） |

**cancel() 执行逻辑**：
1. 停止总训练计时器 `Timer.workout`
2. 停止所有动作独立计时器 `_timers`
3. 停止组间休息 `hideRest()`
4. 停止名言轮播 `stopQuote()`
5. 重置所有状态：`active`、`exerciseRecords`、`pendingExercises`、`_reps`、`_timers`、`startTime`
6. 跳转回首页

**与 end() 的区别**：
| 操作 | end() | cancel() |
|------|-------|----------|
| 保存训练记录 | 保存到 localStorage | 不保存 |
| 清空训练状态 | 是 | 是 |
| 停止计时器 | 是 | 是 |
| 停止名言轮播 | 是 | 是 |
| 返回首页 | 是 | 是 |

### 事件绑定
```javascript
// app.js bindWorkout() 中
document.getElementById('btn-cancel-workout').addEventListener('click', () => {
  if (confirm('确定取消本次训练？所有记录将不会保存')) {
    Workout.cancel();
    this.syncWorkoutTimerUI();
    this.showPage('home');
  }
});
```

## 实现步骤
1. 在 `index.html` 训练页头部添加"取消训练"按钮
2. 在 `js/workout.js` 添加 `cancel()` 方法
3. 在 `js/app.js` 的 `bindWorkout()` 中绑定取消按钮事件
4. 在 `css/style.css` 添加取消按钮样式（红色文字）

## 测试要点
- 训练页头部显示"取消训练"按钮，位于"结束训练"左侧
- 点击后弹出确认框，取消操作不执行
- 确认后计时器停止、名言消失、状态清空
- 回到首页显示"今天还没有训练记录"
- 训练记录中不包含已取消的训练
- 未开始计时（pendingExercises 状态）时也可取消
