# 2026-05-11 重复添加运动覆盖数据修复

## 涉及文件
- `js/workout.js`
- `js/app.js`

## Bug 描述

### Bug：重复添加相同运动会覆盖已记录的运动次数
- **现象**：添加一个运动后，记录运动次数（组数），再次添加相同运动时，之前记录的运动次数全部丢失，只剩下空的运动栏目
- **原因**：`addExercise()` 方法中使用 `filter` 过滤掉所有相同 `exerciseId` 的记录（包括已记录的组数），然后添加一个空记录
- **修复**：
  1. `addExercise()` 方法改为先检查运动是否已存在，如果存在返回 `false`
  2. `app.js` 中根据返回值判断，重复添加时显示 toast "该动作已添加"

## 修改详情

### workout.js - addExercise 方法
```javascript
// 修改前
addExercise(exerciseId) {
    if (!this.exerciseRecords) this.exerciseRecords = [];
    // 如果该动作已存在，清除旧记录后重新添加（防止残留数据阻塞）
    this.exerciseRecords = this.exerciseRecords.filter(r => r.exerciseId !== exerciseId);
    this.exerciseRecords.push({ exerciseId, sets: [] });
    return true;
},

// 修改后
addExercise(exerciseId) {
    if (!this.exerciseRecords) this.exerciseRecords = [];
    // 如果该动作已存在，忽略重复添加
    if (this.exerciseRecords.some(r => r.exerciseId === exerciseId)) {
      return false;
    }
    this.exerciseRecords.push({ exerciseId, sets: [] });
    return true;
},
```

### app.js - 添加动作按钮事件
```javascript
// 修改前
Workout.addExercise(id);
select.value = '';
Workout.renderWorkoutExercises(document.getElementById('workout-exercises'));
Workout.showToast('动作已添加');

// 修改后
if (Workout.addExercise(id)) {
    select.value = '';
    Workout.renderWorkoutExercises(document.getElementById('workout-exercises'));
    Workout.showToast('动作已添加');
} else {
    Workout.showToast('该动作已添加');
}
```
