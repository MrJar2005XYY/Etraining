# 2026-05-10 训练计时器暂停功能修复

## 涉及文件
- `js/app.js`

## Bug 列表

### Bug 1：暂停按钮图标永远不变
- **现象**：无论暂停还是运行，按钮始终显示 `⏸`，没有切换为 `▶`
- **原因**：按钮 HTML 写死了 `⏸`，点击处理只切换了 `.paused` class（控制数字透明度），未更新按钮内容
- **修复**：新增 `syncWorkoutTimerUI()` 函数，根据 `Timer.workout.running` 状态同步按钮图标（⏸/▶）和数字透明度

### Bug 2：暂停后切换页面再回来，视觉状态丢失
- **现象**：暂停计时器 → 切到其他页面 → 切回训练页，按钮图标和暂停样式不正确
- **原因**：`showPage('workout')` 没有恢复计时器的视觉状态
- **修复**：在 `showPage('workout')` 中调用 `syncWorkoutTimerUI()` 恢复状态

### Bug 3：结束训练后 UI 状态未重置
- **现象**：暂停状态下结束训练，按钮仍显示 `⏸`，数字仍为半透明
- **原因**：`Workout.end()` 只调用了 `Timer.workout.pause()`，没有同步 UI
- **修复**：在结束训练的点击处理中，`Workout.end()` 之后调用 `syncWorkoutTimerUI()` 重置按钮图标和样式
