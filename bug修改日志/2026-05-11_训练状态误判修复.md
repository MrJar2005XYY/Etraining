# 2026-05-11 训练状态误判修复

> 提交时间：2026-05-11 22:09

## 涉及文件
- `js/workout.js`
- `js/app.js`

## Bug 描述

### Bug：添加动作但未开始计时，首页误显示"训练进行中"
- **现象**：从底部导航栏进入训练页，添加一个动作但没有点击"开始训练"，回到首页后显示"训练进行中..."
- **原因**：`app.js` 中添加动作按钮的事件处理里，直接将 `Workout.active` 设为 `true`，但计时器从未启动。首页 `renderHome()` 只检查 `Workout.active`，无法区分"已添加动作"和"训练真正进行中"
- **修复**：引入 `pendingExercises` 数组，将"添加动作"和"启动计时器"解耦。`active` 仅在计时器启动后才为 `true`

```javascript
addExercise(exerciseId) {
    if (!this.exerciseRecords) this.exerciseRecords = [];
    if (this.exerciseRecords.some(r => r.exerciseId === exerciseId)) {
      return false;
    }
    this.exerciseRecords.push({ exerciseId, sets: [] });
    return true;

// 修改后
addExercise(exerciseId) {
    if (this.active) {
      if (this.exerciseRecords.some(r => r.exerciseId === exerciseId)) {
        return false;
      }
      this.exerciseRecords.push({ exerciseId, sets: [] });
    } else {
      if (this.pendingExercises.some(r => r.exerciseId === exerciseId)) {
        return false;
      }
      this.pendingExercises.push({ exerciseId, sets: [] });
    }
    return true;
},
```
