# 2026-05-10 组间休息功能修复

## 涉及文件
- `js/workout.js`
- `js/app.js`

## Bug 列表

### Bug 1：计时器结束后不自动关闭休息弹窗
- **现象**：倒计时到 0 后弹窗一直卡住，必须手动点"跳过休息"
- **原因**：`Timer.rest.onComplete` 只调用了 `playBeep()`，没有关闭弹窗
- **修复**：在 `onComplete` 回调中增加 `this.hideRest()` 调用

### Bug 2：切换休息时长 UI 不同步（实际未复现）
- **现象**：点击不同休息时长按钮后显示不更新
- **原因**：经代码审查，`Timer.rest.start()` 内部已调用 `onTick`，UI 更新逻辑正常，归入 Bug 4 的持久化问题

### Bug 3：快速连续完成多组时休息弹窗重复触发
- **现象**：短时间内连续点击"完成此组"，弹窗闪烁或计时器被重置
- **原因**：`showRest()` 没有防重入保护
- **修复**：新增 `_restShowing` 标志位，`showRest()` 入口处检查，`hideRest()` 中重置

### Bug 4：休息时长选择不持久化
- **现象**：用户选了 90 秒休息，关闭弹窗后再打开回退到默认 60 秒
- **原因**：休息时长选择只存在 DOM 的 `active` class 中，未持久化
- **修复**：选择时写入 `localStorage('fit_rest_duration')`，页面加载时恢复

## 额外修复
- `Workout.end()` 中原来只调用 `Timer.rest.stop()`，改为调用 `this.hideRest()`，确保结束训练时弹窗也一并关闭
