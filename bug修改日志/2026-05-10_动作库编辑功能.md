# 2026-05-10 动作库添加行内编辑功能

## 涉及文件
- `js/exercises.js`
- `css/style.css`

## 问题描述
- 动作创建后无法修改名称和类型
- 代码中已有 `update()` 方法，但 UI 层没有编辑入口

## 修复方案

### exercises.js
- 新增 `_editingId` 状态，记录当前正在编辑的动作 ID
- `renderList()`：当 `_editingId` 匹配时，该行变为编辑表单（输入框 + 下拉框 + 保存/取消按钮）
- 新增 `handleEdit(id)`：设置编辑状态，聚焦输入框
- 新增 `handleSave(id)`：读取输入值，调用 `update()` 保存，刷新列表和下拉框
- 新增 `handleCancelEdit()`：清除编辑状态，恢复显示

### style.css
- 新增 `.exercise-edit`：编辑表单 flex 布局
- 新增 `.exercise-edit-actions`：保存/取消按钮容器
