# 2026-05-10 添加动作功能修复

## 涉及文件
- `js/workout.js`
- `js/app.js`
- `css/style.css`

## Bug 列表

### Bug 1：删除动作后，训练中的卡片变空白
- **现象**：从动作库删除某动作后，训练中已添加的该动作卡片完全消失（空白 DOM）
- **原因**：`renderWorkoutExercises()` 中 `Exercises.getById()` 返回 null 时直接 `return ''`，整张卡片不渲染
- **修复**：当 `ex` 为 null 时，使用记录中快照的 `exerciseName` / `exerciseType` 渲染卡片；所有 `ex.id` 引用改为 `rec.exerciseId`

### Bug 2：重复添加动作无反馈
- **现象**：点击"添加动作"按钮无反应，用户以为没添加成功
- **原因**：`addExercise()` 检测到重复时直接 `return`，无任何提示
- **修复**：`addExercise()` 返回 boolean，handler 中检查返回值，显示 toast "该动作已在训练中"

### Bug 3：添加成功无视觉反馈
- **现象**：添加成功后用户不确定是否生效
- **修复**：添加成功后显示 toast "动作已添加"

## 新增功能
- `Workout.showToast(msg)` 方法：页面底部弹出黑色半透明提示，2 秒后自动消失
- `.toast` CSS 样式：fixed 定位，底部居中，带渐入渐出动画
