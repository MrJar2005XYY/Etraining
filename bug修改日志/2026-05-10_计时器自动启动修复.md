# 2026-05-10 修复添加动作时计时器自动启动

## 涉及文件
- `js/app.js`

## 问题描述
- 上一个修复中，添加动作时调用 `Workout.start()` 会导致计时器自动启动
- 用户只想添加动作，不希望计时器立即开始计时

## 修复方案

### 添加动作 handler
- `Workout.start()` 改为只设置 `Workout.active = true` 和初始化 `exerciseRecords`
- 不调用 `Timer.workout.reset()` 和 `Timer.workout.start()`
- 计时器不会自动启动

### 首页"开始训练"按钮
- 如果 `Workout.active` 为 false → 调用 `Workout.start()`（完整初始化）
- 如果 `Workout.active` 为 true 但计时器未运行 → 只启动计时器，保留已添加的动作
- 如果计时器已在运行 → 直接跳转训练页
