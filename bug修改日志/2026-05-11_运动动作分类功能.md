# 2026-05-11 运动动作分类功能

## 涉及文件
- `js/exercises.js`
- `js/workout.js`
- `index.html`
- `css/style.css`

## 功能描述
为每个运动动作添加锻炼部位分类，便于用户识别运动锻炼的身体部位。

## 修改详情

### 1. 数据结构扩展
- 添加 `category` 字段到运动对象
- 定义分类列表：胸部、背部、腿部、腹部、肩部、手臂、核心、全身
- 预设动作添加分类：俯卧撑(胸部)、深蹲(腿部)、仰卧起坐(腹部)等
- 兼容旧数据：为无分类的运动设置默认值 "未分类"

### 2. 动作库页面改造
- `add()` 方法：添加 `category` 参数
- `renderList()` 方法：显示分类标签，编辑模式添加分类选择器
- `handleAdd()` 方法：读取分类值
- `handleSave()` 方法：保存分类值

### 3. 运动选择器优化
- `populateSelect()` 方法：显示格式改为 `动作名 [分类]`

### 4. 训练卡片显示分类
- `renderWorkoutExercises()` 方法：在运动卡片头部显示分类标签

### 5. CSS 样式
- 添加 `.ei-category` 分类标签样式（绿色背景白色文字）

## 验证方式
1. 打开动作库页面，确认预设动作显示绿色分类标签
2. 添加新运动时可选择分类
3. 编辑运动时可修改分类
4. 训练页添加运动后，卡片显示分类标签
5. 运动选择器显示分类信息
