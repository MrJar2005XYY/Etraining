# 每日报告 Skill

## 触发条件
当用户输入以下任意内容时触发：
- `/daily-report`
- `/每日报告`
- "生成今日报告"
- "今日总结"

## 功能描述
生成健身软件项目的每日开发报告，包括：
1. 今日代码变更统计
2. Bug 修复记录
3. 新增功能
4. 待办事项

## 执行步骤

### 1. 获取 Git 变更
```bash
git log --since="today" --oneline
git diff --stat HEAD~$(git log --since="today" --oneline | wc -l)
```

### 2. 读取 Bug 修改日志
扫描 `bug修改日志/` 目录下今天日期的文件。

### 3. 生成报告格式

```markdown
# 每日开发报告 - [日期]

## 代码变更
- 提交数量：X 次
- 修改文件：X 个
- 新增行数：+X
- 删除行数：-X

## Bug 修复
- [列出今天修复的 bug]

## 新增功能
- [列出今天添加的功能]

## 待办事项
- [根据项目状态生成待办]

## 项目统计
- 总提交数：X
- 今日训练记录：X 条
```

## 输出位置
将报告保存到 `每日报告/` 目录（如不存在则创建），文件名格式：`YYYY-MM-DD_每日报告.md`
