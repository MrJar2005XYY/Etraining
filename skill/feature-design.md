# 功能设计 Skill

## 触发条件
当用户输入以下任意内容时触发：
- `/feature-design`
- `/功能设计`
- "设计新功能"
- "功能规划"

## 功能描述
帮助用户设计和规划健身软件的新功能，包括：
1. 功能需求分析
2. 技术方案设计
3. 文件结构规划
4. 实现步骤

## 执行步骤

### 1. 收集需求
询问用户以下信息：
- 功能名称
- 功能目标
- 用户场景
- 优先级（高/中/低）

### 2. 分析现有代码
- 扫描项目结构
- 识别相关文件
- 评估影响范围

### 3. 生成设计文档

```markdown
# 功能设计 - [功能名称]

## 需求概述
- **目标**：[功能目标]
- **用户场景**：[使用场景]
- **优先级**：[高/中/低]

## 技术方案
### 涉及文件
- [列出需要修改或新建的文件]

### 数据结构
- [定义相关数据结构]

### 接口设计
- [定义函数/方法接口]

## 实现步骤
1. [步骤 1]
2. [步骤 2]
3. ...

## 测试要点
- [测试用例 1]
- [测试用例 2]

## 风险评估
- [潜在风险及解决方案]
```

## 输出位置
将设计文档保存到 `功能设计/` 目录，文件名格式：`YYYY-MM-DD_功能名称.md`
